# XMCL 初版界面设计

用户已于 2026-10-25 确认先按深色森林液态玻璃方案创建，后续迭代。

## 范围
以 C++17、Qt 6.5+、Qt Quick / QML 和 CMake 创建原生桌面应用 XMCL。首版实现可运行的界面：主页、实例库、下载管理、设置。界面使用中文，默认窗口 1320 × 860，最小 1060 × 720，保留系统标题栏以支持窗口管理。

## 视觉与交互
深绿背景、方块森林湖泊插画、薄荷绿强调色。使用圆角、背景采样模糊、透明渐变、细边缘高光构成玻璃面板。支持关闭玻璃效果和界面动画。导航、卡片、主要按钮具备悬停和键盘焦点反馈。首页包括欢迎标题、探索主视觉、当前实例、启动入口和快捷操作。实例库支持搜索、选择示例实例；下载页提供明确标记的模拟下载和暂停、继续、取消；设置页支持内存、玻璃和动画选项并持久化。

## 数据边界
C++ LauncherController 管理示例实例、选中实例、内存设置与视觉偏好，使用 QSettings 本地保存。未接入微软认证、Java 检测、版本下载或真实游戏启动。示例账号和实例清楚标示；点击启动显示说明弹窗，不宣称已启动游戏或文件已安装。模拟下载只保留在内存中。

## 验收
CMake 构建通过。Qt Test 验证实例索引边界、内存边界、设置保存和读取。加载真实 QML 并验证页面切换及启动提示。运行桌面应用并导出首页与子页面截图检查文字、圆角、裁切、布局和玻璃效果。README 提供编译运行方法、功能范围和平台验证情况。
