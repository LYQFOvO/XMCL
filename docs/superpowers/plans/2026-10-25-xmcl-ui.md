# XMCL UI Implementation Plan

> **For agentic workers:** Execute in this session. The user has approved implementation; no additional design approval is needed.

**Goal:** 创建具有森林液态玻璃视觉的可运行 C++ Minecraft 启动器 UI。

**Architecture:** C++ QObject 状态控制器与 QSettings 保存偏好。Qt Quick 负责响应式布局与视觉；公用 GlassPanel、Icon、ActionButton 等小组件供四个页面使用。

**Tech Stack:** C++17, CMake 3.21+, Qt 6.5+ Quick / QuickControls2 / Test.

## Global Constraints

- 项目名 XMCL，中文界面，窗口默认 1320 × 860、最小 1060 × 720。
- 不接入认证、真实下载、游戏启动；演示数据和模拟操作必须有明确说明。
- 图像资产打包在 Qt 资源中；不依赖联网展示。
- 用户偏好持久化；所有输入验证边界。

- [x] 1. `src/LauncherController.h`, `src/LauncherController.cpp`, `tests/tst_controller.cpp`：先写实例索引、内存边界和设置重载测试；创建最小接口观察失败；实现并通过 Qt Test。
