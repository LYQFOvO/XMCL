## 已运行验证

- `cmake --build build -j4`：当前本机应用及全部测试可构建。
- `ctest --test-dir build --output-on-failure`：12 组通过（最后验证以 `build/Testing/Temporary/LastTest.log` 为准）。
- UI 测试从生产 QML 验证：下拉菜单折叠/展开/选中/悬停的文字与背景对比度 ≥ 4.5:1、未登录账号入口直达微软登录、设备码提示、安装弹窗真实回环下载与失败重试、社区资源搜索与安装；截图写入 `build/ui-verified/`。
- 真实网络联调：`XMCL_LIVE=1` 下微软设备码申请、Mojang 官方版本清单、Modrinth 搜索/版本/文件下载均通过；`XMCL_LIVE_OLD_INSTALL=1` 下真实安装 Minecraft 1.0，库与资源摘要全部校验后发布。
- BMCLAPI 镜像：地址映射规则来自官方文档并逐条单元测试；`XMCL_LIVE_MIRROR=1` 下真实镜像版本清单与 authlib-injector 组件下载通过；下载器对镜像节点 5xx/限流/连接中断保留 `.part` 有限重试；镜像不可用时自动回退官方源（元数据与文件均支持，同一任务内记住回退状态）。完整镜像模式安装（Minecraft 1.0）实测完成：本机网络对部分镜像 CDN 节点重置连接，程序自动回退官方源，约 9 分钟完成，468 个资产摘要全部校验；纯镜像 CDN 直连路径未在本机跑通。
